# NOVA BANK - Digital Banking Web Application

NOVA BANK is a modern Business & Financial Web Application for easy money management. Users can view their dashboard, transfer money, track transactions, pay bills, plan budgets, set savings goals and manage their virtual debit card - all in one place.

## ✨ Features

### 1. Dashboard
- Total Account Balance: Rs. 248,500
- Monthly Income: Rs. 97,000
- Monthly Expenses: Rs. 24,800

### 2. Money Transfer
- Transfer money to any account
- Enter Recipient Name, Account Number and Amount

### 3. Transactions History
- Complete history of Salary, Shopping, Bills, Freelance Payment, Transport
- Shows Date, Category, Amount and Status

### 4. Bill Payments
- Pay Electricity, Gas, Internet and Water bills
- Enter Consumer / Reference Number and pay

### 5. Financial Tools
- Budget Planner - Plan your expenses
- Savings Goals - Set your savings goals

### 6. My Cards
- Virtual Debit Card - **** **** **** 4821
- Card Status: Active
- Lock Demo Card option
